# Poligorn website (v.1.2)

Минималистичный RU/EN сайт‑портфолио разработчика игр (Poligorn) с витриной проектов (Itch.io — **ручной список**), резюме и блоком студии **Tea Agency Games**.

Включает в себя:
- **Главную страницу** с проектами.
- **Интерактивный граф Zettelkasten** по базе знаний "Brain Gamedesign".
- **Свой чат Poligorn Connect** вместо прямой ссылки на Telegram (на базе Supabase).
- Возможность скачивания резюме в PDF-формате.

## Локальный запуск

Сайт использует статический генератор [Astro](https://astro.build/) и React-компоненты для визуализации.

```bash
npm install
npm run dev
```

## Сборка и деплой

```bash
npm run build
npm run preview
```

Сборка складывается в `dist/` — это удобно для деплоя на статический хостинг (Reg.ru). 

Для работы динамических компонентов (например, базы знаний и чата) необходимо настроить переменные окружения Supabase (в `.env`). Убедитесь, что публичные ключи добавлены на хостинг.

## Контент

- Соцсети: `src/content/socials.ts`
- Проекты: `src/content/projects.ts` (источник правды — ручной список, типизировано, RU/EN поля)
- Резюме (навыки/места работы): `src/content/workplaces.ts`, `src/content/resume.ts`
- Интерактивный граф (база знаний): `docs/telegram_webhook.ts` (вебхук для парсинга постов с Telegram-канала) + `src/components/BrainGraph.tsx` (визуализатор).

Высокоуровневые требования и архитектура зафиксированы в `.cursor/rules/*.mdc` и папке `docs/`.
